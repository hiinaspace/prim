prim

A small shared video room for friends, with desktop and VR modes. This is an early test build; please keep this link within the friend group.

Download

Prim 0.3.9 for Linux and Windows adds wrist mic/deafen controls, companion movement, Monado/WayVR compatibility options and experimental SteamVR peek. Includes media sharing, subtitles, spatial voice and livestream playback. No separate .NET installation is needed.

  • Windows x64 installer
  • Linux x64 AppImage
  • Windows portable ZIP (optional)

Everyone in a room needs 0.3.6 or later; update to 0.3.9 to try the new companion features.

Linux 0.3.3 fixes startup on systems without Nix. If an older AppImage cannot open, download the new one here once.

Getting started

  1. Windows: run the installer. These builds are not code-signed, so Windows may show an unknown-publisher warning. A custom installation folder can be selected with --installto "D:\Games\prim".
  2. Linux: make the AppImage executable (chmod +x Prim-friends-linux.AppImage), then run it. Choose Install in user folder or another folder, close the download copy, and open the installed copy for future use. If FUSE is unavailable, run APPIMAGE_EXTRACT_AND_RUN=1 ./Prim-friends-linux.AppImage.
  3. Choose Play. Prim tries VR if available and otherwise opens in desktop mode. Use Enable VR or Disable VR in the Room menu while staying connected. Keep the launcher open while playing.

Allow several GB of free space for the game and update staging. If you used the earlier localhost test launcher, download this version once to switch to the friends update feed.

NixOS

Download prim-shell.nix beside the AppImage. Build the runtime and keep its prim-runtime symlink as a garbage-collection root:

nix-build prim-shell.nix -A runtime -o prim-runtime
nix-shell prim-shell.nix --run 'prim-launcher-fhs -c ./Prim-friends-linux.AppImage'

The launcher's install buttons preserve this FHS wrapper in the installed shortcut. Keep the runtime root while using it.

Playing another VR game

With VR enabled, launch your game and keep Prim connected for voice and tracked head/hands. Use Prim’s desktop menu, WASD and click-to-capture mouse yaw while the game is active. Closing the game returns Prim to the headset. Open Prim in headset can deliberately replace a game after confirmation.

Monado supports the lift-up/peek view. SteamVR uses background tracking by default; enable Comfort → Experimental SteamVR peek to try stereo peek. Linux SteamVR peek was headset-tested locally; Windows overlay testing is still needed. During peek, look at either wrist to mute or deafen. Deafen silences incoming Prim audio only; your microphone stays independent.

If unpatched WayVR covers Prim, try Comfort → Draw Prim above other overlays. This also covers WayVR panels while Prim is visible. If runtime activity is unknown, use the lift gesture or Reveal Prim room.

Sharing a video

Anyone can browse, paste or drop a local video in Movie, then choose to share it with the room or play it only locally. Friends receive shared videos automatically. The provider can set an upload limit and approve individual viewers if they need a relay in Sharing. Voice remains connected while media waits for approval. Received files are cached temporarily, not saved as downloads.

For a livestream, paste its playback URL in Movie. Prim supports externally hosted streams, including RTSP over TCP; configure OBS and your streaming server separately.

Updates and troubleshooting

The launcher checks for updates on startup. Read the changelog, click Download update, close prim, then click Install and restart. Nothing is installed automatically.

If files seem broken, use Verify files or Repair installation. If the launcher itself cannot start, download it again here.

For help, choose Create support report, then Open report folder. The ZIP contains selected system information and text logs with basic scrubbing. Review it before sending it to me; nothing is uploaded automatically.
