# Prim 0.3.5

- The room host can share a local video file directly with friends from the Sharing tab. Pause, seek and playback stay synchronized; guests do not need a public URL or their own copy.
- Shared files use a bounded temporary memory cache and an adjustable host upload limit. If a viewer needs an Iroh relay, the host must approve media for that viewer and share. Voice stays connected while approval is pending.
- Avatars now animate their mouths from local and received voice, with a local mirror comparison and neutral mouths after mute or silence.
- Includes the portable Linux launcher fixes from 0.3.3.

Everyone in a room must update to 0.3.5 because the connection protocol changed. OBS livestreaming and overlay mode are not included yet.

Validated with six Linux clients and automated native checks. Real Internet relay transitions, native Windows and headset behavior still need friend testing.
