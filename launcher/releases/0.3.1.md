First friends launcher release. The game is the existing feedback-4 build.

- Check for updates at startup, with download and installation only when clicked.
- Verify or repair the installation and export a local support report.
- Production downloads and signed update feeds now live at prim.hiina.space.

Existing test launchers need this download once to switch from the localhost feed.
