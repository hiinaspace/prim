# prim 0.3.3

- Fix Linux launcher startup on machines without Nix: use the portable .NET
  executable host instead of the build machine's Nix-specific host.
- Fix bundled libmpv’s absolute mujs dependency and host graphics-library discovery
  on ordinary Linux installations.
- Keep the VRM avatars and articulated hands introduced in 0.3.2.

If your Linux launcher cannot open, download the AppImage from prim.hiina.space
once. Existing working launchers can install this release normally.
