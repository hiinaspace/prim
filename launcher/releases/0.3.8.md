# Prim 0.3.8

- Keep your tracked head and hands in Prim while playing another SteamVR game. Voice, media and the room stay connected; the desktop menu and WASD remain usable.
- Prim returns to the headset when the game closes. “Open Prim in headset” lets you deliberately take over after confirmation; SteamVR may close the other game.
- Monado companion overlays support the lift-up/peek gesture, with haptic feedback and independent desktop/VR menus. SteamVR currently supports background tracking without the peek view.
- Includes the Linux runtime compatibility fix from 0.3.7.

Tested locally with Linux SteamVR/Beyond/Index controllers and Monado, including repeated handoffs and remote avatar delivery. The Windows package passed desktop startup under Wine; native Windows SteamVR still needs friends testing.

Quick test: enable VR, launch a game, confirm friends still see your head/hands, close the game, and check Prim returns. Repeat, then disable VR. Please report runtime/headset and which step failed if anything goes wrong.
